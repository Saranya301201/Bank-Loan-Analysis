# Bank Loan Analysis | Excel Dashboard

## Project Overview

This project analyzes bank loan application data using Microsoft Excel  to evaluate lending performance, monitor loan funding and repayment trends, and understand borrower characteristics. The analysis transforms raw data into meaningful business insights through data cleaning, KPI calculations, exploratory data analysis, and interactive dashboard development.

The dashboard enables stakeholders to explore loan applications, funded amounts, received payments, loan status, and monthly lending trends to support data-driven decision-making.

## Business Objectives

- Analyze overall loan application volume and lending activity.
- Monitor total funded amounts and total amounts received.
- Track Month-to-Date (MTD) and Month-over-Month (MoM) performance.
- Evaluate loan distribution by purpose, grade, status, and borrower characteristics.
- Examine interest rates and debt-to-income (DTI) ratios.
- Present key lending metrics through an interactive dashboard.

## Key Performance Indicators (KPIs)

| KPI | Purpose |
|---|---|
| Total Loan Applications | Measures application volume |
| Total Funded Amount | Measures the total amount disbursed |
| Total Amount Received | Tracks payments received |
| Average Interest Rate | Measures the average interest rate |
| Average DTI Ratio | Measures borrowers' average debt-to-income ratio |
| MTD Loan Applications | Tracks applications for the current reporting month |
| MTD Funded Amount | Tracks funding for the current reporting month |
| MTD Amount Received | Tracks payments received during the current reporting month |
| MoM Growth | Measures change against the previous month |
